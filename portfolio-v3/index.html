Project 02 · AI + MCP · BI reporting
AI-Powered BI Reporting Using a Context Engine & MCP

The idea: reports need trusted data in the right shape. Here the data comes from a context engine, and AI with MCP tools loads it into Power BI and Tableau reports, so each report isn't wired up by hand.

  • Context engine as the source: I take the data for the reports from the context engine and load it into the BI reports.
  • AI and MCP do the loading: MCP-enabled workflows for Power BI, and XML-based configurations for Tableau, built with GitHub Copilot.
  • Faster development: repeated dashboard development tasks are automated, which improves development efficiency and streamlines analytics workflows.
  • Tested end to end: I check data accuracy, performance and alignment with business requirements for both Power BI and Tableau dashboards.
